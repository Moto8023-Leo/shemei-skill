## 已完成的 12 项优化

### 1. 参数安全表达（Range Safe Expression）
- **文件**：`scripts/facts.py`（新建）
- **功能**：自动检测产品规格中的区间值（如"45-55km"），修正为本地化限定表达（"UP TO 55KM RANGE"支持 6 种语言）
- **覆盖**：区间清洗、绝对声明检测、全文合规校验、AI 提示词注入规则
- **修改**：`scripts/content_factory.py` — 注入安全规则到主提示词 + 审核 pass；`server.py` — 返回 safetyViolations/safetyBlocking 到前端

### 2. 请求去重（5分钟指纹缓存）
- **文件**：`server.py`（修改）
- **功能**：`/api/generate` 端点 SHA-256 请求指纹去重，5 分钟内相同参数复用结果
- **验证**：首次调用 20.2s，第二次调用 2.0s，返回同一 taskId

### 3. 飞书表「折扣代码」独立字段
- **文件**：`server.py` + `scripts/feishu_driver.py`（修改）
- **功能**：PublishRequest 增加 `discount_code` 字段，mark_generated 支持 discount_code 参数，发布回写包含折扣代码

### 4. 统一前端 API 客户端
- **文件**：`web/src/utils/api.ts`（新建）
- **功能**：统一 fetch 包装器：15s 默认超时、指数退避重试（最多 2 次）、完整类型定义、HTTP 状态码中文化

### 5. 内容版本历史
- **文件**：`scripts/version_engine.py`（新建）+ `server.py`（新增 3 个 API）
- **功能**：每次生成/重排版/审核/发布/恢复自动创建版本快照，支持版本列表、对比（Diff）、恢复
- **API**：`GET /api/versions/{id}` / `GET /api/versions/{id}/compare` / `POST /api/versions/{id}/restore`

### 6. 逐平台发布前审核 UI
- **文件**：`web/src/pages/workbench/RightRail.tsx`（重写）+ `web/src/App.css`
- **功能**：3 项全局确认（产品完整/无遮挡/事实准确）+ 每平台 3 项（文案/图片/账号），全部勾选解锁发布按钮
- **联动**：安全违规自动阻止发布，按钮文案动态变化

### 7. 四层质量评分体系
- **文件**：`scripts/quality_engine.py`（重写）+ 前端 RightRail
- **功能**：blocking（阻止发布）/ warning（优化提醒）/ manual（人工检查）/ passed（已通过）四层分级
- **UI**：Blocking 红色 ⛔ / Warning 橙色 ⚠ / Manual 蓝色 👁 / Passed 绿色 ✅ 折叠展示

### 8. Creative Seed 确定性随机
- **文件**：`scripts/visual_engine.py`（重写）+ `server.py`
- **功能**：SHA-256 种子驱动可复现视觉风格选择，支持风格锁定和重新随机

### 9. 内容去重检测
- **文件**：`scripts/similarity_engine.py`（新建）+ `server.py`
- **功能**：五维度相似度检测（Hook/卖点/CTA/场景/构图），0-100 风险评分，中文建议

### 10. 1.5 秒自动保存草稿
- **文件**：`web/src/store/useStudioStore.ts`（修改）+ `server.py`（新增 2 个 API）
- **功能**：localStorage + 后端双重持久化，debounced 1.5s 自动保存，失败 ~30s 自动重试
- **API**：`PUT /api/drafts/{key}` / `GET /api/drafts/{key}`

### 11. 图片文字覆盖拖拽编辑器
- **文件**：`web/src/utils/canvasOverlay.ts`（修改）
- **功能**：新增 OverlayForm 参数 — 字体缩放（0.5-2.5x）、面板透明度（0.3-0.95）、文字对齐方式（左/中/右）

### 12. Prompt 中心版本化管理
- **文件**：`web/src/pages/Settings.tsx`（重写）
- **功能**：5 类提示词模板（文案/图片/产品保护/平台/节日），编辑自动创建新版本，版本切换/历史查看

## shemei_skill 保留的独特优势

以下方面不受影响，持续优于 v2.3 Node.js 版：

1. **多页面路由架构** — 10 个独立页面对运营更友好
2. **TDesign 组件库** — 专业 UI，比纯 CSS 维护成本低
3. **多品牌独立表** — 每品牌 3 张飞书表，数据隔离更干净
4. **Daemon 守护进程** — Python 定时任务比进程内队列更稳健
5. **X/Twitter 双通道** — twikit API + Chrome 浏览器回退
6. **Canvas 客户端合成** — 比服务端 SVG 合成更灵活
7. **Zustand 状态管理** — 比单体 useState 更模块化
